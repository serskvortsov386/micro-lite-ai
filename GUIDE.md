# 📘 Руководство по дообучению MicroLiteAI

## С чего начать?

MicroLiteAI создан так, чтобы каждый мог обучить его на своих данных.

---

## 📝 Шаг 1: Подготовка датасета

1. Откройте файл `data/dataset.txt`
2. Добавьте свои тексты (каждое предложение с новой строки)
3. Сохраните файл

**Пример:**
```
Ёжик нашёл большой гриб под дубом.
Он был очень рад своей находке.
Ёжик понёс гриб домой к своим друзьям.
```

**Рекомендации:**
- Минимум 20-50 предложений для хорошего результата
- Используйте тексты, на которые у вас есть права
- Для стихов — пишите каждую строчку с новой строки

---

## ⚙️ Шаг 2: Создание токенизатора

```bash
cd src
python tokenizer.py
```

Что произойдёт:
- Токенизатор прочитает `data/dataset.txt`
- Создаст словарь из 100-500 слов
- Сохранит его в `models/tokenizer.json`

---

## 🧠 Шаг 3: Обучение модели

```bash
python train.py
```

**Параметры обучения (в коде):**
- `embed_size=64` — размер встраивания
- `num_heads=4` — количество голов внимания
- `num_layers=4` — количество слоёв трансформера
- `epochs=50` — эпох обучения
- `seq_length=32` — длина последовательности

**Время обучения:** ~5-10 минут на CPU

**Результат:** `models/model.pth` — файл с весами

---

## 🎨 Шаг 4: Генерация текста

```python
from tokenizer import MicroLiteTokenizer
from model import MicroLiteModel

# Загрузка
tokenizer = MicroLiteTokenizer()
tokenizer.load('models/tokenizer.json')

model = MicroLiteModel.load('models/model.pth')

# Генерация
text = model.generate(
    tokenizer,
    prompt="ёжик",
    max_length=40,
    temperature=0.7,
    top_k=8
)
print(text)
```

**Параметры генерации:**
- `max_length` — длина текста (20-100)
- `temperature` — креативность (0.5-0.9). Меньше = предсказуемее
- `top_k` — количество вариантов для выбора (5-20)

---

## 🔧 Шаг 5: Настройка модели под себя

### Изменение архитектуры

В `src/model.py` измените параметры:

```python
model = MicroLiteModel(
    vocab_size=tokenizer.vocab_size,
    embed_size=128,    # Больше → точнее, но медленнее
    num_heads=8,       # Больше → лучше, но требует ресурсов
    num_layers=6,      # Больше → лучше, но требует ресурсов
    max_seq_len=256    # Больше → длиннее контекст
)
```

### Изменение обучения

В `src/train.py` настройте:

```python
epochs = 100           # Больше → лучше, но дольше
batch_size = 16        # Зависит от памяти
learning_rate = 0.001  # Скорость обучения
```

## 📈 Как оценить результат

### 1. Смотрите на потери (loss)
- Начало: 2-3
- Хорошо: < 1.0
- Отлично: < 0.5

### 2. Тестируйте генерацию

```python
test_prompts = ["ёжик", "гриб", "лес"]
for prompt in test_prompts:
    print(model.generate(tokenizer, prompt))
```

### 3. Проверяйте разнообразие

Генерируйте один и тот же промпт несколько раз — текст должен меняться

## 🆘 Частые вопросы

**Q: Модель генерирует бессвязный текст?**
A: Добавьте больше данных в датасет. 10-20 текстов — минимум для осмысленной работы.

**Q: Модель повторяет одни и те же слова?**
A: Уменьшите `temperature` (0.5-0.6) и увеличьте `top_k` (10-15).

**Q: Как использовать несколько персонажей?**
A: Добавьте тексты про разных персонажей в датасет. Модель научится различать их.

**Q: Можно ли использовать русский и английский вместе?**
A: Да, токенизатор работает с обоими языками.
