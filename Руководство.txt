================================================================================

ЧТО ТАКОЕ MICROLITEAI
================================================================================

MicroLiteAI — это микроскопическая языковая модель (всего 224,000 параметров),
созданная в образовательных целях. Она показывает, как работают нейросети,
генерирующие текст.

✅ Размер модели: ~0.9 MB
✅ Обучение на CPU: 5-10 минут
✅ Полностью открытый код
✅ Возможность дообучения

УСТАНОВКА И НАСТРОЙКА

ПОДГОТОВКА ДАТАСЕТА
================================================================================

Откройте файл data\dataset.txt

Добавьте свои тексты (каждое предложение с новой строки)

Сохраните файл

Пример:

Ёжик нашёл большой гриб под дубом.
Он был очень рад своей находке.
Ёжик понёс гриб домой к своим друзьям.

Рекомендации:

Минимум 20-50 предложений

Используйте только свои тексты или тексты с открытой лицензией

Для стихов — каждая строчка с новой строки

================================================================================

ГЕНЕРАЦИЯ ТЕКСТА
================================================================================

Создайте файл generate.py в корневой папке:

import sys
sys.path.append('src')

from tokenizer import MicroLiteTokenizer
from model import MicroLiteModel

Загрузка
tokenizer = MicroLiteTokenizer()
tokenizer.load('models/tokenizer.json')

model = MicroLiteModel.load('models/model.pth')

Генерация
prompt = "ёжик"
text = model.generate(
tokenizer,
prompt=prompt,
max_length=40,
temperature=0.7,
top_k=8
)
print(f"Промпт: {prompt}")
print(f"Ответ: {text}")

Запуск:
python generate.py

================================================================================

ДООБУЧЕНИЕ МОДЕЛИ
================================================================================

Добавьте новые тексты в data\dataset.txt (старые можно оставить)

Запустите обучение заново:
cd src
python train.py

Модель дообучится на всех данных — старых и новых.

Параметры настройки в коде (src\train.py):

epochs = 50 (количество эпох)

batch_size = 8 (размер батча)

learning_rate = 0.001 (скорость обучения)

================================================================================

ЧАСТЫЕ ВОПРОСЫ
================================================================================

ВОПРОС: Модель генерирует бессвязный текст
ОТВЕТ: Добавьте больше текстов в датасет (минимум 20-50 предложений)

ВОПРОС: Модель повторяет одни и те же слова
ОТВЕТ: Уменьшите temperature (0.5-0.6) или увеличьте top_k (10-15)

ВОПРОС: Где сохраняется обученная модель?
ОТВЕТ: В папке models\model.pth

ВОПРОС: Как использовать другого персонажа?
ОТВЕТ: Замените тексты в data\dataset.txt на нужного персонажа

ВОПРОС: Можно ли использовать коммерчески?
ОТВЕТ: Код — MIT, датасет — CC BY-NC. Для коммерческого использования нужны
свои тексты.

ВОПРОС: Модель не запускается, ошибка с Python
ОТВЕТ: Проверьте версию Python (должна быть 3.8+)
